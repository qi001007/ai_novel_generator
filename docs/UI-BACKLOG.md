# UI 待办（完成即删）

本文件只保留尚未完成、能在界面上验收的条目。过程、提交、测试数字和已完成事项不留在这里；行为闭环见 AGENTS.md。

## P0 · v1 闭环

### 35.1 C 层重新生成后无法应用

- [ ] 对已有剧情弧重新生成时，提案必须保留现有弧主键与起止章；模型省略的 `收束`、`状态`由当前文档补齐，不得把合法更新卡成结构错误。
- [ ] 作品 6 实测点击应用返回成功，`arcs.md` 与渲染视图同步更新，刷新后不返红。

验收：保存应用请求/响应；弧记录数与主键不变，至少一个可编辑字段发生变化。

### 35.2 B 层重新生成后无法应用

- [ ] 对已有目录重新生成时，只接受逐章 `## 第 N 章 章名` 记录；禁止把“第 11-30 章 弧 3”这类范围摘要伪装成 `toc.md`。
- [ ] Agent 在展示提案前必须得到结构化失败并自我修正；作品 6 应用后 `toc.md`、目录渲染和数据库一致。

验收：应用请求成功；现有章号集合不变；范围标题不会进入待应用卡。

### 35.3 提案展开后可以收起

- [ ] “展开全部 N 行改动”切换为“收起改动”，点击后恢复 8 行摘要且不改变提案内容或状态。

验收：同一张长提案连续点击展开、收起，DOM 行数从完整值回到不超过 8 行。

### 35.4 自然语言创建章节与简报必须形成真实业务闭环

- [ ] “创建第一章，先写简报”生成合法 `chapters/0001/brief.md` 提案；主人点击应用后，同一文件 PUT 事务创建 Chapter 与 ChapterBrief。
- [ ] 左侧章节树立即出现第一章，右侧简报 Markdown 可编辑；刷新后仍存在。

验收：从无章节作品开始完成一次对话→提案→应用，章节列表由 0 变 1，禁止仅生成不存在的临时文件标签。

### 35.5 自然语言创建人物卡必须形成真实业务闭环

- [ ] 创建人物使用合法 `settings/characters/new.md` 提案，不再生成不存在的 `settings/characters.md`。
- [ ] 主人点击应用后由唯一文件 PUT 分配人物 ID，左侧人物树与人物卡同步出现；刷新后仍存在。

验收：人物数增加 1；返回数字人物文件路径；不存在“没有这个文件”红字。

### 35.6 对话 Agent 业务能力契约

- [ ] 自然语言意图统一路由到 A/B/C 更新、章节/简报创建更新、人物创建更新的规范文件路径与 schema；Agent 只提案，主人确认后才写。
- [ ] 模型输出不得直接成为可应用卡：必须先经过路径白名单、严格结构校验与一次有界自修复；修复仍失败时显示诊断，不提供成功假象。

验收：上述五类动作各有端到端测试；不存在第二写接口或 Agent 绕过确认直接落库。

### 32.4 B 层生成必须实时落到提案与渲染层

- [ ] 对话 Agent 生成 B 层目录时，流结束后必须出现 `toc.md` 完整提案卡，主人点击应用前不得写入真源。
- [ ] 应用提案后，源码编辑器与列表渲染视图都显示同一份最新目录；已有列表视图在提案确认前不伪装成已写入。

验收：测试覆盖 B 层提案事件、应用后 `toc.md` 读取与列表刷新；真机生成 B 层时可看到提案卡和逐步增长的列表内容，且拒绝提案不改变服务端文件。

## P1 · 真实使用后修

### 30.5 伏笔压缩

- [ ] 本章埋设或回收的伏笔给全文；其他开放伏笔压成“标题 · 埋于 X · 预计 Y”。
- [ ] 压缩清单有总字符上限，超限原因在注入清单可见。

触发条件：3 章交付验收中伏笔开始挤压 12000 字预算；未触发不阻塞 v1。

### 30.6 本章伏笔提示

- [ ] 本章没有埋设/回收计划时显示可忽略提示，不弹窗、不阻塞生成。
- [ ] 向导答案只能形成提案，主人应用后才写伏笔和简报。

### 30.7 人物匹配

- [ ] 简报点名但人物库未精确匹配的名字在清单中明示，不静默丢失。
- [ ] 正文出现疑似未建档人物时提供预填新建入口；AI 不能自动建卡。

### 31.4 工具轨迹刷新后消失

- [ ] 界面明确说明轨迹只属于当前流，或把结构化步骤持久化后在历史消息中恢复。

此项需要 schema 决策，不阻塞 v1；不能继续显示一个刷新后永远为空的“工具轨迹”入口。

### 设定面板接线

- [ ] 伏笔墙与世界观地图读取真实数据；没有后端能力的动作隐藏或标为未开放。
- [ ] 世界观/伏笔文档如保留“跳到字段”动作，必须提供真实入口；否则移除该承诺。

主人已要求这一组后置，不阻塞 v1。

- 完成后把结论更新到 WORKSTREAM-PLAN.md，并从本文件删除该条。
