- [ ] 本轮只登记，未改（工作规则 2）。要裁的是「统一成顶层字段」还是「在拒绝文案里把该工具的完整写法逐字递回去」：前者动工具表 schema，后者只动一句文案。

验收：同一类误用在假网关重放，返回的文案能点出该工具的真实参数形状（或该次调用直接被接住）；两类工具的参数面在 `docs/` 里有一处写明，不再靠模型试出来。
