# 需求清单

对应 PRD v0.3 的功能拆解与勾选。完成一项勾一项；需求变更先改 PRD，再同步到这里。

图例：`v1` = 重构后第一个可用版本；`P2` = 第二阶段。

## 1. 页面与导航

- [ ] v1 书架首页：封面卡片墙、作品统计、新建作品向导
- [ ] v1 工作台三栏布局：左双根树 / 中对话流 / 右编辑器
- [ ] v1 双根树：规划（A/B/C/D 层级）与设定库两个根节点
- [ ] v1 树节点状态徽章：草稿 / 已审 / 定稿（中文标签）
- [ ] P2 树节点右键快捷操作（跳转、重命名等）

## 2. 对话 Agent

- [ ] v1 混合对话流：流水线消息卡片 + 自由追问
- [ ] v1 斜杠命令：/generate、/review、/summary、/feedback、/search
- [ ] v1 斜杠命令面板：输入 / 弹出候选、支持过滤
- [ ] v1 @引用：像 Codex 一样引用规划/设定/章节节点
- [ ] v1 流式消息更新
- [ ] v1 对话 Agent 与写文 AI 分离，独立模型配置（新增 `NOVEL_LLM_CHAT_MODEL`）

- [ ] v1 内联审稿：审稿意见锚定正文片段，高亮 + 批注气泡
- [ ] v1 审稿侧栏：展开完整七维审稿报告（一致性/角色/节奏/连贯/伏笔/钩子/文风）
- [ ] v1 Ctrl+F 快速查找
- [ ] v1 自动保存（防抖 + 保存状态指示）
- [ ] v1 版本历史侧栏（人工编辑保存为新版本）
