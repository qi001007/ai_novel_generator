# 项目进度与收尾计划

最后核对：2026-09-10。本文件是唯一进度入口，只回答：已经能用什么、v1 还差什么、下一步做什么。

## 1. 当前结论

项目不是“框架未成”，而是“主链已成、最后一段交互未闭合”。数据边界、规划写入口和上下文资料池已经收口；继续大范围重构只会推迟可用日期。

当前策略：先完成一次可由主人真实使用的“对话 → 确认 → 生成 → 编辑 → 导出”闭环，再以实际使用暴露的问题决定是否做高级编辑和视觉扩展。

## 3. v1 结束前必须完成

按顺序一次只做一项：

### P0-1 对话触发章节生成

状态：已完成基础闭环。ChatPane 已提供“确认并生成”动作，点击后复用既有 `/generate` 与章节流式生成端点；没有新增 Agent 写工具，前端命中测试已覆盖该调用。

目标：主人能在对话里要求“生成第 N 章”，Agent 先展示将使用的章节与动作；主人点击确认后，复用现有章节流式生成端点，不给 Agent 增加任意写文件工具。

验收：

- 自然语言能定位作品内的目标章；缺简报时明确拒绝并给出入口。
- 确认卡展示目标章、模型任务和注入清单摘要。
- 只有主人点击确认才生成；取消、刷新和重复点击不会写入。
- 真网关在隔离作品完成一章，正文可继续编辑和导出。

### P0-2 调整写作上下文

实现 UI-BACKLOG 的 30.1、30.2、30.4 已完成；还需用真实作品做一次真机验收：

- B 目录与 C 剧情弧统一使用前后 20 章窗口；B 只带标题、剧情功能和备注。
- 上一章简报与完整正文进入必注入档；不得再带其他章正文。
- 清单明确显示范围、字符数、未命中人物与被裁原因。

30.5 的伏笔压缩与 30.7 的人物候选识别在真实 10 章试用中若触发预算或漏人，再作为 v1 修复；不先做推测性 NLP。

### P0-3 收 Agent 双引擎尾巴

- Pydantic 路径已补同参数去重，离线契约测试通过，行为与 legacy 对齐。
- 默认引擎切换仍待完成；切换前必须先跑一次真网关冒烟并确认流式、工具失败、预算和提案链路。
- legacy 先保留为回退；v1 验收后下一次维护再删除，不让删代码阻塞交付。
- 工具轨迹是否持久化不阻塞 v1；当前刷新后丢失必须在界面或文档中如实说明。

### P0-4 v1 验收

- 新建隔离作品，完成规划、对话触发生成、编辑、审稿、终审、导出与恢复。
- 连续生成至少 3 章做交付验收；产品价值验证仍按 PRD 的 10 章试用。
- 全部门禁通过；关键页面逐页真机截图并由主人审核。
- 修正截图中阻塞使用的缺陷；非阻塞美化进入延期清单。

## 4. 明确延期，不阻塞 v1

| 延期能力 | 原因 |
|---|---|
| 双栏对照、选区 Diff、内联审稿、版本历史 | 高价值但不是生成与取稿的前置 |
| Token 聚合总账 | 单次用量已有；聚合可后补 |
| 反馈自动写回 A/B/C/D | 需要独立确认语义，现有影响分析可保留 |
| 伏笔墙、世界观地图完整交互 | 主人已要求后置；真实数据与面板壳已存在 |
| 生图与绘画详情真数据 | 当前 key 无图片权限；不做假功能 |
| 磁盘双向同步、跨作品检索、向量 RAG | 增加冲突或基础设施成本，v1 无真实失败证据 |
| 全面拆分大文件 | 只在后续需求触及对应区域时精准拆分 |

## 5. 当前风险

- 默认仍是 legacy；Pydantic 去重已完成，但真网关冒烟与默认切换仍未完成。
- 上下文窗口代码已按目标收口，尚缺真实 10 章作品的字符数、未命中与预算验收数据。
- styles.css、ChatPane、PreferencesPage、WorkbenchPage 与多个后端 service 过大；只做局部修改，避免顺手重构。
- 生产构建主 JS 约 874 KB；本地 v1 不因提示线延期，只有真实启动变慢才做路由懒加载。
- 前端测试有两处既有 act(...) 警告；测试仍通过，触及相应用例时再修。
- GitHub Actions 文件存在，但本轮只核对了仓库配置，没有把远端运行状态当作已验证事实。

## 6. 不再等待主人的选择

- 世界观不整体升为必注入；只保护被本章/简报明确引用的设定，避免 12000 字预算被长设定吃满。
- 生图延后，直到配置有图片权限的供应商。
- 反馈写回、工具轨迹持久化和高级编辑全部不阻塞 v1。
- 误建作品属于主人数据操作，不混进开发待办；现有删除与恢复入口已经可用。

## 7. 完成定义

“项目完成 v1”同时满足：

1. P0-1 至 P0-4 全部通过；
2. PRD 的核心闭环能由主人在真机独立完成；
3. 没有假按钮、静默失败或第二真源；
4. 未做能力在界面明确标为未开放或不显示；
5. 全部门禁退出码为 0，截图经主人确认；
6. 延期项留在本文 §4，不再伪装成 v1 未完成。
