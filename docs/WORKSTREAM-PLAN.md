## 一、已经能用的

**写一本长篇的主链**
- 四层规划都能在界面里直接改：A 全本蓝图、B 目录、C 剧情弧、D 单章简报；改完下一次生成就带上。
- 正文生成：按简报生成整章，边生成边显示，写完落库；生成时读了哪些资料全部列得出来。
- 机械校验：按简报里的「必要事实」逐字检查正文有没有写到，没通过会明说缺哪条。
- 审稿记录、AI 自检、通过终审、打回、事实落库：一条链都能点通，数据是真的。
- 章摘要、事实提取：有真数据，不是占位。

**资料与上下文**
- 全书只有一个资料池，对话和正文生成共用它 —— 不会出现「聊天时看到的和写正文时看到的不一样」。
- 上下文有预算（默认 12000 字），挤不下的那份会**明写在界面上**，不会悄悄丢。
- 注入清单按 A→B→C→D 排，**一份文件一行**，点开能看到这份文件每一节的原文（今天刚改的）。

**对话与 Agent**
- 对话可选模式（计划 / 写作）、能 @引用资料、能带附件 —— 附件真的进了模型输入
  （铁证：上传一个只存在于临时目录的文件，模型回答了里面唯一那句话）。
- Agent 能自己读文件、搜网页、多步推理，最后给「提案」，你点应用才写进文档。
  **它没有直接改你稿子的权力**，注册表里就没有写工具。
- 每条 AI 回复带可折叠的思考过程。

**界面**
- 书架：书卡右键 = 打开 / 更换封面 / 编辑信息（书名、简介、目标章数上限、文风约束）/
  删除（必须把书名原样打一遍才能删）。
- 设置：模型接入（多个供应商，正文生成、审稿、章摘要、对话各走哪家）+ 外观
  （主题三卡 + 强调色 / 代码配色 / 界面字号 / 正文字号 / 三种字体，含英文字体）。
- 深浅色 × 两色系 × 两代码配色 × 两档字号，全部真机量过对比度与点击命中区。

**可靠性（都是踩出来的坑换来的）**
- 数据库是唯一真源，`.md` 文件是它的投影；改这些文档**只有一条入口**。
- 删一本书会把它名下 14 张表的记录一起删干净，且不会碰到别的书（有测试钉住）。
- 人物删除按钮以前点了必然报错（端点根本不存在），今天补上了。
- 界面有一套「不许改回去」的自动断言（`frontend/src/uiInvariants.test.ts`）：
  改了界面不改断言，测试直接红。

## 二、还差什么（这就是「没做」的完整清单）

|---|---|---|
| 伏笔墙 / 地图面板 | 面板里一个请求都没发；数据其实有（伏笔两条实测进过注入清单） | 看着像「这功能没做」，其实是没接线 |

| 选区改稿（框选一段 → 只改这段 → 逐处接受/拒绝） | 没做（设计帧早就批了） | 日常改稿只能整章重新生成 |
| 双栏对照生成 | 没做 | 同上 |
| 内联审稿（高亮 + 批注气泡 + 七维报告） | 没做 | 审稿只能在对话里看 |
| 章内查找 `Ctrl+F`、版本历史侧栏、自动保存状态 | 没做 | 长稿必备 |
| 目录列表选中行后自动滚动定位 | 差这一小条，其余都完成 | 点小节不会跳过去 |
| 绘画详情页 | 右侧全是页面壳假数据；**这台网关的 key 不允许调生图（实测 401）** | 要么换供应商，要么继续如实写「未启用」 |
| Token 用量汇总页 | 单次调用详情有，按功能/日期聚合的总账没有 | 看不出钱花在哪 |
| 活跃章节与规划联动展示 | 没做 | 设定库看不到「这个人现在在哪几章」 |
| 反馈写回（`/feedback` 影响分析 → 确认后写回 A/B/C/D） | 没做 | 反馈只能看不能落 |
| 角色状态时间线、事实冲突提示 | 没做 | 长篇最容易崩的地方，目前没有防线 |
| 删章节 / 中间插入章节 / 改文件名 | **故意未开放**：章号是主键，删一章要不要顺延后面的号还没定 | 界面上写着「未开放」，不是坏了 |
| 全部需求条目走完一遍 + 全页面真机截图给你验收 | 没做 | 收尾 |
| CI | 没做，门禁全靠本地跑 | 忘跑就推了 |

## 三、接下来我做什么（按这个顺序，一条做完一条交一条）

1. **伏笔墙 + 地图接上真数据** —— 面板已经在了，只缺读。风险最低，先做。
2. **对话式管理接上正文生成** —— 让 Agent 能触发「生成这一章」，仍然只走那一条写入口。
   这一步必须真调模型验证，会产生少量 token 费用（我会在隔离库里跑，不动你的作品）。
3. **Token 用量汇总页** —— 按功能、按日期聚合，能下钻到单次调用。
4. **选区改稿**（编辑器高级能力里最影响日常写作的一条）—— 然后是双栏对照、内联审稿、查找、版本历史。

6. **收尾**：全页面截图给你过目、需求条目逐条核、CI。

关于「什么时候能做完」：这个项目没法按人日换算 —— 我一次会话能做完**一条**并把它验证到位
（测试全绿 + 真机截图自己看过 + 单独提交推送）。按这个口径：第 1、3 条各一次会话；
