# UI 设计清单 v2（最终版目标设计）

本文件是前端实现的唯一界面依据。每个页面按五段写清：**框架 / 功能点 / 按钮 / 风格 / 交互**。实现顺序：本清单 → Figma 全页面设计稿 → 前端代码 → 主人审批。

设计模式声明（impeccable）：本产品全部界面属于 **Operate 模式**（完成任务型工具）——可扫读、一致性、键盘效率优先于装饰表达；品牌感只活在精确的细节里。设计刻度：变化 5/10、动效 3/10、密度 7/10（工作台 7，书架 4）。

反俗套纪律（taste-skill 适用部分）：单一强调色全局锁定；禁紫罗兰渐变、禁玻璃拟态、禁 AI 三等分卡片阵；一套圆角系统全局一致；图标单库统一描边；每个动效必须能用一句话说出理由。

## 0. 设计系统（令牌）

### 0.1 色彩

强调色为朱砂红：印章/批注是中国长篇写作的文化母题，产品里所有"行动、选中、AI 产出"都指向它。中性色用冷暖居中的石墨灰，不用发黄的纸色。

| 令牌 | Light | Dark | 用途 |
|---|---|---|---|
| `bg` | `#F8F8F7` | `#131314` | 应用底色 |
| `surface` | `#FFFFFF` | `#1C1C1E` | 面板、卡片 |
| `surface-alt` | `#F1F1EF` | `#26262A` | 悬浮、选中、输入框底 |
| `border` | `#E4E4E1` | `#313134` | 结构线（面板分隔、输入描边） |
| `text-1` | `#1C1B1A` | `#ECEBE9` | 主文本 |
| `text-2` | `#73716C` | `#9D9B96` | 次要文本、占位 |
| `accent` | `#C2492F` | `#E06A4E` | 主按钮、选中态、链接、AI 产出标记 |
| `accent-soft` | `#FBEDE9` | `#3B2B27` | 选中底色、徽章底 |
| `success` | `#2F7D46` | `#5CB176` | 定稿、已配置 |
| `warning` | `#A8811F` | `#C9A227` | 编辑中、生成中 |
| `danger` | `#DC2626` | `#F87171` | 破坏操作、校验失败 |

规则：正文对比度 ≥ 4.5:1；状态色只用于徽章/点，不大面积铺色；focus ring 统一 accent 2px。

### 0.2 字体

| 用途 | 字体 | 规格 |
|---|---|---|
| UI 界面 | 思源黑体 Noto Sans SC（400/500） | 阶梯 12/13/14/15/16/20/24/32，行高 1.5 |
| 正文阅读与编辑 | 思源宋体 Noto Serif SC（400/600） | 17px，行高 1.9，段距 0.75em |
| 动态数字 | 界面字体 + `font-variant-numeric: tabular-nums` | 字数、token、时间防跳动 |

规则：界面文字最小 12px；标题 `text-wrap: balance`，正文 `text-wrap: pretty`；根节点 `-webkit-font-smoothing: antialiased`。

### 0.3 几何

- 圆角体系：控件 6px，卡片/弹层 10px；嵌套同心（外 = 内 + padding）。
- 间距阶梯：4/8/12/16/24/32/48。
- 阴影只做海拔：弹层 `0 8px 24px rgb(0 0 0 / 0.12)`（dark 0.4）；卡片默认靠 border 分层，悬浮加 `0 4px 12px rgb(0 0 0 / 0.08)`。
- 面板之间 1px border 分隔；不用 border 制造按钮立体感。

### 0.4 图标

统一 `lucide-react`，strokeWidth 1.5；一处一种描边；图标用 `currentColor`，状态靠 CSS 不换资源；图标按钮必须有 `aria-label` + Tooltip；点击区 ≥ 40x40（桌面紧凑），移动端 44x44。

### 0.5 动效（make-interfaces-feel-better 全量采用）

| 场景 | 规格 |
|---|---|
| 通用状态过渡 | 150ms ease-out，只过渡 opacity/color/transform，禁 `transition: all` |
| 弹层进出场 | 进 200ms 上移 8px + 淡入；出 150ms 下移 4px + 淡出；可被打断 |
| 按压反馈 | `active: scale(0.96)`，禁更小值 |
| 首屏 | 不播放入场动画 |
| 批量入场 | 语义分组 stagger 100ms；高频交互（打字/悬停）零动画 |
| 流式输出 | 600ms 呼吸光标块；正文直接追加，不逐字动画 |
| 降级 | `prefers-reduced-motion` 全部直出终态 |

规则：动效永远不是唯一反馈，每个动画状态都有静态线索（颜色/图标/文字）。

### 0.6 组件基础

- **按钮**：primary（accent 底白字）/ secondary（surface 底 + border）/ ghost（hover 显 surface-alt）/ danger（danger 底）。高 32（紧凑）/ 36（标准），圆角 6，字重 500；加载中转 spinner 并禁点。
- **输入框**：高 36，surface-alt 底，focus 2px accent ring；错误 danger ring + 下方 12px 错误文案。
- **徽章**：高 20，圆角 4，11px：草稿灰 / 编辑中 warning / 已审 success / 定稿 success 填充 / 生成中 warning + spinner。
- **弹层**：模态与确认气泡两种；Esc 关闭、焦点困住、关闭后焦点归还。
- **空态**：lucide 图标 + 一句话 + 一个主按钮，居中，无装饰插画。
- **加载**：列表骨架屏（与最终布局同形），按钮内 spinner，流式用光标。
- **错误**：行内红字 + 建议 + 重试；toast 只用于后台结果（保存失败、导出完成）。

## 1. 书架首页 `/`

**框架**：极简单页。顶栏 56px（左字标，右主题切换 + 设置）；内容区最大宽 1280 居中；书卡 CSS Grid `repeat(auto-fill, minmax(260px, 1fr))`，间距 24。

**功能点**：作品列表（封面、书名、字数、章节进度、最近编辑）；新建作品向导（弹窗三步：书名简介 → 篇幅文风 → 确认）；删除作品（输书名确认）；搜索（>10 本出现）；空态引导。

**按钮**：`新建作品`（primary，页头右）；书卡悬浮 `继续写作 →`（primary 小号）；卡右上 `...` 菜单（打开/重命名/删除）；向导 `上一步 / 创建`。

**风格**：书架是全应用唯一允许展示感的页面——封面区用书名首字大号衬线字 + accent-soft 底，像书脊；卡片 10px 圆角，悬浮 `translateY(-2px)` + 阴影 + 继续写作淡入。

**交互**：整卡可点进工作台；悬浮 150ms；删除走红色确认气泡；创建成功 toast + 跳转；键盘 `N` 新建、`/` 搜索。

## 2. 工作台 `/novels/:id`

### 2.1 整体框架

VSCode 式四段：**顶部栏 48px → 工作区三栏（可拖拽）→ 底部状态栏 24px**。

- 顶部栏：左 = 返回书架 + 书名 + 当前卷徽章；中 = `Ctrl+K` 命令入口提示条；右 = LLM 状态点（绿已配/黄未配，点击弹配置指引）、`用量`、主题切换、设置。
- 工作区：左栏（树，默认 280px，240-420 拖拽，可折叠成 48px 图标条）｜中栏（对话流，默认 440px，360-560 拖拽）｜右栏（编辑器占剩余）。分隔条 4px 热区；当前交互栏顶部 2px accent 线。

### 2.2 左栏：双根树

**功能点**：根 1"规划"（A 全本蓝图 → B 目录 → C 卷/弧 → D 章节，缩进 16px）；根 2"设定库"（人物/世界观/伏笔/地点/阵营）；树内过滤框（输入即筛、命中高亮、自动展开路径）；状态徽章；右键菜单（打开/重命名/删除）；拖拽排序（B/D，P2）；当前打开节点 accent-soft 底 + 左 2px accent 线；生成中章节行内 spinner 徽章。

**按钮**：树底固定小图标排：`新建章节`、`过滤`、`折叠全部`；节点 hover `...`。

**风格**：react-arborist，行高 32，13px；缩进虚线引导线；徽章 11px 纯文字色右对齐。

**交互**：单击预览、双击固定编辑目标；上下箭头移动、左右箭头折叠、`Enter` 打开；拖拽目标行显示插入线。

### 2.3 中栏：对话流（Codex 式）

**框架**：消息滚动区（flex-1）+ 底部输入坞。

**功能点**：
1. 消息四型：用户气泡（右，surface-alt）；AI 回复卡（surface，流式追加 + 尾部光标）；命令卡片（命令名 + 对象 + 状态徽章 + 进度/结果 + token 明细行 + 操作按钮）；错误卡（danger 左线 + 原因 + 重试）。
2. 斜杠命令面板（cmdk）：`/` 唤起，候选含命令名、参数占位、说明；上下键选择，`Tab` 补全。
3. `@` 引用选择器：节点搜索，选中生成可删引用 chip。
4. 消息级 token 明细：底部 `模型 · 耗时 · 展开用量`，展开显示输入/输出/总计（tabular-nums）。
5. 消息操作：hover `复制 / 引用到输入框 / 重试`。
6. 上下文指示：输入坞上方小字显示将带入的上下文（当前章节 + @引用）。

**按钮**：`发送`（primary，Enter 发送 / Shift+Enter 换行）；生成中变 danger `停止`。

**风格**：对话区 bg 底；命令卡左 2px accent 线；引用 chip accent-soft。

**交互**：流式自动吸底，用户上滚暂停并浮出"回到最新"；Agent 与写文 AI 用左边线颜色区分（Agent=accent，写文=success）。

### 2.4 右栏：编辑器（写作页）

**框架**：Tab 页签条 36px → 工具栏 40px → 正文区。页签可多开章节，未保存显实心 accent 点，中键关闭。

**功能点**：
1. 正文编辑（TipTap）：衬线 17px/1.9，页宽 720 居中；2s 防抖自动保存，显示 `已保存 HH:mm / 保存中...`。
2. Ctrl+F 查找条：命中高亮 + 计数 + 上下键跳转，Esc 关。
3. 双栏对照生成：左当前版右 AI 新稿（流式滚动），逐段 `采纳此段`，顶部 `全部采纳 / 放弃`；合并写入版本历史。
4. 选区修改：框选浮出工具条（`AI 修改 / 复制 / 批注`）→ Diff 视图（删除线暗红、新增 accent-soft）→ 逐处 `接受 / 拒绝`。
5. 内联审稿：问题片段 warning 高亮 + 批注气泡（维度+摘要+原文证据，可标已处理）；`审稿报告` 开右抽屉（420px）列七维：结论/证据/建议 + 总评分。
6. 版本历史：时钟图标开左抽屉，版本（时间+来源），预览 diff、确认后回滚。
7. 工具栏常驻：章节标题、状态徽章、字数、保存状态。

**按钮**：`审稿报告`、`版本历史`、`双栏对照开关`、`导出本章`；Diff `全部采纳 / 放弃`；抽屉 `重新审稿`。

**风格**：编辑区是唯一衬线主舞台，chrome 全部无衬线退后；正文区无边框卡片，只有页宽留白。

**交互**：Esc 退出 Diff/查找；批注 hover 显完整证据；历史 diff 用同一 jsdiff 渲染；保存失败状态变 danger + toast 重试。

### 2.5 底部状态栏

24px：左 = 后端连接点 + 当前书/章；右 = 今日 token 用量（点击进用量页）、字数、版本号；11px text-2。

### 2.6 全局快捷键

`Ctrl+K` 命令面板｜`Ctrl+P` 快速打开章节｜`Ctrl+F` 查找｜`Ctrl+S` 保存｜`Ctrl+B` 折叠左栏｜`Ctrl+J` 折叠中栏｜`Esc` 关闭弹层。

## 3. 人物卡片库（点设定库→人物打开，替换中+右栏）

**框架**：工具行（分类 Tab：全部/主角团/重要配角/小 Boss/龙套 + 搜索框 + `新建人物`）+ 卡片墙（Grid minmax(220px,1fr)）+ 详情大弹层（900px：左 1/3 头像与基本字段，右 2/3 页签：档案/关系/弧线/出场章节）。

**功能点**：人物卡（头像首字色块、姓名、级别徽章、活跃章节范围 `45-78`、一句话身份）；搜索按姓名/别名/身份；详情层即点即编辑；关系条目双向显示；预计出现窗口 vs 实际出现并排，偏离时 warning 提示确认；删除输姓名确认；P2 导入/导出。

**按钮**：`新建人物`、详情 `保存 / 取消 / 删除`、卡片 hover `编辑 / ...`。

**风格**：卡片 10px 圆角 surface；级别色带：主角团 accent / 重要配角 text-1 / 小 Boss warning / 龙套 text-2；详情层字段 12px 标签 + 14px 值两栏栅格。

**交互**：Tab 切换保留搜索词；卡片 hover 抬升 2px；保存成功行内 toast；Esc 退详情。

## 4. Token 用量页

**框架**：替换中+右栏：维度分段控件（按功能 / 按日期）+ 汇总卡行（今日/本周/总计 token）+ 明细表。

**功能点**：明细列 = 时间、功能、模型、输入/输出 token、耗时；行下钻单次调用 prompt 摘要；聚合条形图（纯 CSS，无图表库）；空态。

**按钮**：`导出 CSV`（secondary）。

**风格**：行高 36，斑马纹 surface-alt；数字右对齐 tabular-nums。

**交互**：聚合条 hover 显精确值；切换维度保持筛选。

## 6. 全场景状态表（每页必须实现）

| 场景 | 规格 |
|---|---|
| 空态 | lucide 图标 + 一句话 + 主按钮；书架空态"你的第一部作品从这里开始" |
| 首次加载 | 骨架屏与最终布局同形，不整页转圈 |
| 生成中 | 命令卡生成中 + 树行 spinner + 状态栏字数跳动；输入坞变停止 |
| LLM 未配置 | 顶部黄点 + 对话区置顶提示条（指引 .env + 重新检测按钮） |
| 请求失败 | 行内错误 + 重试；保存失败 toast |
| 断线 | 状态栏红点"后端离线"，输入禁用 |

## 7. 交付前检查（按序执行）

1. **web-design-guidelines**：前端代码完成后，拉取 vercel web-interface-guidelines 全量规则审查，`file:line` 格式输出问题。
2. **make-interfaces-feel-better**：按 19 条细则走查（同心圆角、tabular-nums、0.96 按压、禁 transition:all、击打区、图标描边、动效降级），quick 模式上限 5 条 HIGH/MEDIUM。
3. **硬性项**：对比度 4.5:1、焦点可见、reduced-motion、空/载/错三态齐全、单一强调色、单一圆角体系、数字 tabular-nums。
4. 全部通过后交主人审批。
