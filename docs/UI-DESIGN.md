# UI 设计规格

最后整理：2026-10-23。本文件保存当前视觉与交互决定；完成状态看 `WORKSTREAM-PLAN.md`，待修批注看 `UI-BACKLOG.md`，机器断言看 `frontend/src/uiInvariants.test.ts`。

## 0. 视觉根基

- 沿用原工作台：紧凑、平面、细边框、低饱和、明确层级。Codex 只提供项目启动器和信息组织参考，不覆盖原有视觉性格。
- 避免大渐变、大圆角、发光、大面积宣传文案、漂浮玻璃卡和成排胶囊标签等模板化 AI 产品观感。
- 正文是阅读主舞台，UI chrome 使用无衬线字体并退后；源码、代码和结构化值使用等宽字体。
- 未实现能力禁用并说明原因，不能放置假按钮或只有前端状态的入口。

### 0.1 色彩

实际令牌以 `frontend/src/styles.css` 顶部为准：

| 令牌 | Light | Dark | 用途 |
|---|---|---|---|
| bg | `#f8f8f7` | `#131314` | 应用与编辑底色 |
| surface | `#ffffff` | `#1f2023` | 抬升面 |
| surface-alt | `#f1f1ef` | `#191a1b` | 次级面与输入 |
| border | `#e4e4e1` | `#313134` | 结构线 |
| text-1 | `#1c1b1a` | `#ecebe9` | 主文本 |
| text-2 | `#6d6b66` | `#9d9b96` | 次文本 |
| accent | 朱砂 `#c2492f` | 朱砂 `#e06a4e` | 行动与选中 |
| success | `#2f7d46` | `#5cb176` | 成功 |
| warning | `#8a6a12` | `#c9a227` | 警告 |
| danger | `#dc2626` | `#f87171` | 破坏动作 |

- 蓝色强调由 `data-accent=blue` 切换；深浅主题由 `data-theme` 决定。
- 正文文本对比度至少 4.5:1；高饱和色上的文字使用 `on-accent/on-danger`，不散写白色。
- 分隔优先留白，其次使用 1px 轻线；品牌色不能充当普通结构线。

### 0.2 字体、尺寸与几何

- 尺度只有三层定义：原始阶梯（字体、间距、尺寸）→ 语义令牌（紧凑控件、默认控件、边界、拖拽命中区）→ 组件令牌（工具栏、按钮、输入框、标签页、分界线）；组件规则不得另造同类像素常量。
- UI 使用 `--ui`，正文和成稿使用 `--prose`，代码使用 `--mono`；字体栈只在 `styles.css` 定义。
- 默认 UI 为 14px / 1.5，紧凑控件使用共享的 12px 字级，章节正文为 18px / 1.9，Markdown 源码通过 `--source-font-size` 与 `--source-line-height` 统一为 13px / 20px；行号使用相同行高，Minimap 跟随编辑器字体；动态数字使用 `tabular-nums`。
- 界面字号通过 `--ui-zoom` 缩放；所有指针坐标与拖拽位移必须经过 `toCssPx()`。
- 间距阶梯为 4/8/12/16/24/32/48；圆角为 6/8/10px。
- 独立图标按钮 32×32，行内动作至少 24×24；只有移动端才要求 44×44。
- 三栏宽度、关闭阈值、恢复宽度与夹紧算法只有 `paneLayout.ts` 一个定义处，组件和 CSS 不复制常量。

### 0.3 动效与状态

- 常规过渡 150ms ease-out，只过渡 `opacity`、`color`、`transform`，禁止 `transition: all`。
- 按压使用 `scale(0.96)`；首屏不播放入场动画；流式文字直接追加。
- `prefers-reduced-motion` 下直接到终态；动效不得成为唯一反馈。
- 面板级空态使用 lucide 图标、一句话和一个主动作；列表提示不加装饰图标。
- 短时成功通知显示 4 秒，普通错误通知显示 8 秒，二者均可手动关闭；字段校验留在字段旁，只有完整诊断页面允许持续展示。
- 配置等问题提示必须可关闭，并在保存设置、路由切换、窗口重新获得焦点或从后台恢复时重查；确认问题解决立即移除。提示文案应覆盖实际缺项，不能把未选任务模型一律描述成没有密钥。
- 保存或请求失败留在原位并提供重试；成功路径或导出结果使用统一 Toast，不在页面底部永久占位。

### 0.4 控件纪律

1. 能用图标就不用常驻文字按钮；对象动作在 hover 或 `focus-within` 时出现。
2. 动作贴着对象，不造只装按钮的长条。
3. 一个对象只用一个名字，不用斜杠拼同义词。
4. 状态优先用圆点与颜色；解释性结构文字不上屏。
5. 展开和收起只用一个 chevron，无底框、无主色。
6. 同一信息只出现一次，跨栏重复视为缺陷。
7. 隐藏动作仍须键盘可达，并保留菜单或快捷键入口。
8. 空态、占位、注脚和回执不以句号收尾；正文和模型提示词除外。
9. 聚焦不画外圈或主色光晕，只允许光标和中性强边框。
10. 常规动作是 28×28 或 32×32 的无边框 lucide 图标按钮，必须有中文 `aria-label` 与 `title`。
11. 方框主按钮只留给当前界面的唯一主行动。
12. `Button`、`IconButton`、`TextField`、`Combobox`、`Checkbox`、`Menu`、`Popover`、`Toast` 和 `Splitter` 是业务页面的统一控件入口；业务组件不得重新定义同类字体、控件高度、圆角或边框。

### 0.5 滚动与活动边界

- 滚动条与视口滑块默认隐去，只在悬停、键盘聚焦或拖动时出现；不显示原生两端三角按钮。
- 任何可滚动区域都必须支持鼠标滚轮；不能把拖拽滑块作为唯一翻页方式。
- 编辑画布、源码区、属性面板和长表单在实现前先定义滚动、缩放、分栏轴向、最小值、最大值、越界行为、重载恢复与窄屏降级。
- 可调整边界必须实时跟随指针并稳定限位；内容增长不能把同级区域挤出页面或锁死下半部分。

### 0.9 本轮机器保护与浏览器验收

- B-01：Workflow 树点击流程行（包括再次点击当前选中项）会打开右侧画布，并只切换编辑中的流程；不得因此更改作品的当前流程绑定。
- 2026-10-23 B-02：Workflow 树加载后若当前作品缺正文生成或 AI 自检用途，显示「补齐系统工作流」；统一命令只为完全没有同用途流程的作品创建系统默认与绑定，任何已有同用途流程（包括自建、未发布或未绑定）保持原样。新补流程有已配置模型时发布，无模型则保留草稿并提示；补齐后只刷新列表，不自动试运行模型或改变现有编辑选择。
- 2026-10-23 B-04：供应商折叠态只保留名称、Base URL、密钥掩码与操作按钮，模型目录摘要和条目仅在编辑态显示。折叠只隐藏目录与表单，不保存或清空模型目录、筛选及未保存字段；重新展开恢复原状态。点击“获取模型”时先展开编辑区；请求中手动收起后，响应不得再次展开。目录失败继续通过 Toast 提示。
- B-02：正文工具栏仅在有候选时显示审核入口，共享 Dialog 展示正文和 Token；“稍后处理”关闭弹窗但保留候选，“接受候选”才经文件 PUT 写入。未保存编辑与原稿版本冲突必须拒绝覆盖。候选预览使用共享 UI/字号/行高/主题令牌，最大高度 50vh 内部滚动；桌面与 620px 视口均实测无弹窗溢出，未据此认定三栏窄屏布局完成。
- U-06：三栏在窄视口优先保正文列，正文列可用宽度不得低于 320px。窗口变窄时先自动收起对话栏，仍不足再收起结构栏；编辑器不自动收起，已在窄屏手动关闭的栏不被自动重新打开。自动收起只作用于本次视口，不写入 `localStorage`，窗口变宽按 320px 判据逐级恢复。自动适配只在挂载与 resize 时执行，不打断正在进行的拖拽；手动拖拽与关闭语义不变。真实 Edge 实测：1680 编辑列 934、1266 520、821 仅隐对话栏得 476、620 隐对话栏+结构栏得 576，四档工具栏均 33px。
- F-01：模型目录使用 UI 字体与紧凑字级、默认控件最小行高；行内容可换行，网格行按内容增长，超过目录高度后内部滚动。
- F-02：配置提示的手动关闭、解决后移除、再次缺项时恢复，以及保存后和窗口恢复时的刷新，由行为测试保护；短时通知沿用共享 Toast 生命周期。
- F-03：源码与行号消费统一的 13px / 20px 令牌；控件不另写字体栈。
- F-04/F-05：新建节点只保留工具栏单个菜单及画布右键入口；六类节点共用清单、唯一节点约束与撤销路径。缩放和适配共用三个 IconButton、一个主题背景与裁切边界，无外加阴影底板。
- F-06：React Flow 选中回调保持稳定，相同选择不触发状态更新；StrictMode 回归与真实“返回书架”交互共同验证。
- 对话详情：内容列固定为 `min(100%, 1040px)` 并在视口内居中，只有一列；消息按 18px 行距、10/12px 内边距分卡，用户（主色 12% 底 + 左色条 + 右缩进）、AI（`--surface-alt` + 中性左色条）、命令（告警色底与色条）三种角色可区分；超过 280 字的正文在行内保留带空行段落的纯文本摘要，点「查看全文」在可拖动/缩放的浮窗里查看完整 Markdown，关闭后列表不位移；顶部搜索框按问题、回答、模型与命令过滤并显示命中数。
- M-02：地图库列表用紧凑行卡（缩略图、名称、版本状态、更新时间），右栏头部在 620px 自动换行，不把「AI 生成地图」挤出面板；生成弹窗按“剧情弧 → 章节简报 → 可编辑提示词 → 尺寸 → 费用确认”单列排布，未勾费用或未配置生图模型时原位说明且不发请求；详情页左图右栏，版本历史、确认按钮、提示词与成本字段同栏，未确认草稿用状态标签区分，确认后才成为当前版本。
- M-01：详情页在 1024 对齐画布上提供网格、缩放/平移与四向扩图；扩图弹窗写明“只重绘白色遮罩区，遮罩外逐像素贴回，不羽化、不缩放”，勾选费用后只提交一次。选中格子可单格重绘；历史行显示“扩图 · 向东 / 重绘 · 第 X 列第 Y 行 / 整图生成”。非 1024 对齐画布禁用扩图并说明原因，4×4 到顶后四向按钮禁用。
- V-19：非法连线不弹模态框，而是在目标节点正下方 4px 显示描边气泡（`role="alert"`、11px / 1.5 行高、4 秒自动消失），节点边框同时转危险色；气泡不改变画布布局，也不进入撤销栈。画布多选采用拖框选择（应用启用了 `selectionOnDrag`），节点快捷键以画布视图为作用域：焦点因节点卸载落到 `<body>` 时 Delete / Ctrl+C / Ctrl+V / Ctrl+Z / Ctrl+Shift+Z 仍必须生效，输入框与可编辑区域内不拦截。
- V-20：模型供应商不再分“顶部默认表单 + 其他供应商行”两套格式，所有供应商（含默认）进同一张卡片列表。每行同一套动作（编辑、测试连接、获取模型）与同一组字段（Base URL、API Key、超时；非默认行多一个名称）；默认行带“默认”徽标且没有删除，其余行删除后该供应商名下的任务路由立即回默认。行内徽标区分“已保存密钥 / 未配置密钥 / 未保存”；保存条常驻面板底部，写明“有未保存的修改”或“已保存 HH:MM:SS”，保存成功回读后行内掩码立即更新。默认行不提供改名：后端没有默认名称字段，宁可不给控件也不做假控件。
- G-01/V-19：章节「调用记录」先列该章真实 Workflow 运行行（用途、时间、模型、输入/输出 token），点「详情」进入统一运行详情 `/novels/:novelId/chapters/:chapterId/workflow-runs/:runId`。页头章名取 TOC 当前标题；KPI 五格为输入/输出 token、节点数、模型与耗时；节点按 start / context / prompt / model / output 展开，context 的已注入项带引用原因、未注入项带排除原因，页内明示「模型节点合计 = 运行总计」；右栏列候选 job、接受写入的 `path · revision` 前 8 位与审核结论。详情只读 WorkflowRun / NodeRun 快照，不新增审计表；返回键 28×28、节点行 45px，620px 视口无横向溢出。
- 配置状态按任务实际路由判定（D-22）：任一已命名任务所路由的供应商缺 Base URL、密钥或该任务模型名时，工作台模型 chip 用告警态、对话顶部提示「模型接入未完成」、设置页保存条显示「有任务缺少密钥」，不得显示「已配置」；不能拿默认供应商的密钥替另一个供应商作证。
- 视觉尺寸由真实浏览器在当前桌面视口及 821px 窄屏测量；深色临时验证后恢复原主题。未完成的整体布局问题继续留在反馈文档。

## 1. 作品启动页

- 启动页采用 Codex 项目启动器的层级，但保持原工作台字体、颜色、边框和控件密度。
- 顶栏只保留产品入口、真正居中的搜索和设置；不得在顶栏和作品列表各放一个同义“新建作品”。
- 最近一次打开或写作的作品成为“继续写作”主卡。立体书封用于作品身份和小型预览，不得绑定固定作品。
- 主卡与“最近”列表可以出现同一作品；列表必须覆盖全部未归档作品，并按真实最近使用时间排序。
- 作品行展示小封面、标题、当前卷章、字数、最近编辑时间和状态，不增加无实际用途的数据大屏。
- 置顶与归档没有完整后端语义时不显示；若上线，必须同时具备置顶顺序、取消置顶、归档容器、恢复入口和系列关系。
- 整行打开作品；右键菜单只提供已有后端语义的编辑、导出和删除动作。
- 新建作品向导只收集必要信息；封面预设保留原立体书风格。

## 2. 三栏工作台

### 2.1 框架与拖拽

- 顶部栏 48px；主体为左导航、中对话、右编辑审批三栏。
- 三栏内容必须设置 `min-width: 0`；工具栏空间不足时换行，不把内容顶出可视区域。
- 两个边界均可拖拽；位移与指针保持 1:1，并服从 UI 缩放换算。
- 栏可以在同一拖拽手势中越过关闭阈值后关闭，并在鼠标不松开的情况下反向拖回恢复。
- 关闭后重新打开时使用最近合法宽度；右栏恢复时优先保证正文可读宽度。
- 每本书独立保存栏宽、隐藏栏、当前活动区、标签页、文件和对话；切换作品绝不串状态。
- 三个栏状态按钮必须反映真实显隐状态，不得用高饱和蓝块冒充边界或产生遮挡。

### 2.2 左栏与 Activity Bar

- Activity Bar 顺序固定：文章结构、设定库、地图库、Workflow、对话记录。人物、世界观与伏笔属于设定库内部资源，不重复占一级入口。
- 规划树展示作品主链路、卷、章节规划与正文；人物、世界、地点和事实进入各自资料视图。
- 搜索、折叠、新建和节点动作遵守控件纪律；右键菜单与当前后端能力完全一致。
- Workflow 是工作台一级模块，不放回设置页。

### 2.3 中栏对话

- 支持自由对话、斜杠命令、`@` 引用、附件、流式输出、审批差异和工具执行状态。
- AI 回答不使用头像、大卡框和营销式抬头；思考、工具轨迹与正文是三个独立语义区。
- 工具轨迹使用 Wrench 与“工具轨迹 · N 步”，展示名称、耗时、返回规模、审批和结果，不混入正文。
- 高风险工具调用显示真实差异、拒绝与批准入口；低风险执行完成后提供撤销。
- 用户上滚时暂停自动吸底，并提供“回到最新”。

### 2.4 右栏编辑与 Minimap

- 文件和章节可以多标签打开；标签条横向滚动但不显示滚动条，关闭按钮距离恒定。
- CodeMirror 承担 Markdown 与正文编辑；目录、人物和正文可有专用渲染面，其他 Markdown 默认显示源码。
- 编辑器跟随工作台主题：深色使用 VS Code Dark+ 语义色（背景 `#1e1e1e`、正文 `#d4d4d4`、选区 `#264f78`），浅色使用对应的 VS Code 浅色编辑面；正文、行号、选区、光标和 Minimap 必须同次切换，不留黑色孤岛。覆盖层必须 `inset: 0`。
- Minimap 宽度只由 `--minimap-w: 88px` 定义，字体读取同一正文 token，不能在 JS 和 CSS 各维护一套几何。
- Minimap 是可滚动的文档缩小视图：长文按稳定行距绘制可见区，短文仍保留 36–104px 的稳定视口滑块；视口只在悬停、聚焦或拖动时出现。
- Minimap 支持点击、拖拽和滚轮定位正文；缩略内容、正文和视口滑块实时同步并在上下边界稳定限位，首行与右侧保留安全内边距。
- CodeMirror 长距离跳转后必须在下一动画帧按更新后的 `scrollHeight` 再对齐一次，不能因虚拟布局重估让 Minimap 落点漂移。
- 编辑器和文件编辑器的原生纵向滚动条必须隐藏；Minimap 是唯一可见的纵向滚动轨道。不得在 Minimap 左侧重新出现第二条滑块。
- 标签、源码/渲染切换、审批入口和当前状态在长内容与窄屏下仍须可达。
- 保存、校验、审稿、摘要、终审和调用详情必须明确反馈成功或失败。

### 2.5 作品切换器

- 顶栏显示当前作品并提供快速切换、打开最近作品和返回启动页。
- 使用工作台自己的菜单/弹层，不依赖无法统一主题的原生 `select` 下拉。
- 弹层的背景、边框、阴影、字号、行高、选中态和图标与当前深浅主题一致。
- 文本不得与箭头或图标重叠；作品名过长时单行省略并在 `title` 中保留全名。

## 3. Workflow Studio

- Workflow 视觉必须像专业 IDE：资源/节点库、画布、属性面板、运行详情各司其职，不把所有功能堆成等权卡片。
- 画布是主舞台，占用剩余空间；节点库窄而可搜索，属性面板只在选中节点时显示。
- 节点使用紧凑矩形、细边框和小圆角；端口类型、标题、状态与关键参数有清楚层级，不使用大渐变或发光卡。
- 工具栏按“编辑、视图、运行”分组；常用操作使用图标，发布与运行可保留文字主动作。
- 左侧资源树按正文生成与 AI 自检分组；当前绑定使用紧凑徽标。新建时填写名称并选择固定用途，重命名、复制、设为当前和删除位于资源右键菜单。
- 整图坐标与连线只在画布编辑，不向作者暴露无意义的整图 JSON，也不提供 Workflow 缩略图。提示词模板可从节点属性进入完整编辑面。
- 上下文模块使用可同时打开、拖动、关闭的非模态设置窗，关闭后在当前工作流会话内记住最后合法位置；横向分界线始终只显示 1px 中性结构线。
- 首版节点库只显示开始、动态上下文、提示词模板、模型调用、条件判断和输出六类已实现节点；Python、人工审批、循环和通用平台函数不提前出现。
- 新建节点收在工具栏单个“添加节点”图标菜单，并复用画布空白处右键菜单；菜单支持键盘移动、Escape 关闭及视口边界夹紧。缩放与适配收在同一个主题控件组。
- 每个 Workflow 恰好一个动态上下文节点；模型节点必须从已配置的供应商与模型目录选择，属性面板使用类型化表单，不让作者编辑空白 JSON。
- 节点等待、运行、成功、失败和暂停使用低干扰状态色；错误必须就近显示。
- 运行详情以节点时间线为主，展示输入输出摘要、耗时、Token、错误和重试，不添加无用仪表盘。
- 画布支持右键空白处新建，节点右键复制、断开和删除，键盘删除、框选、多选、复制粘贴、撤销重做、一对多连线、适配全图与全屏；唯一开始、上下文和必要输出节点不可删除。
- 已保存工作流列在左侧资源树；右侧工具栏只保留保存、发布、试运行、全屏和当前画布动作。
- 上下文策略默认折叠为模块摘要，展开后按模块编辑；画布与策略之间可纵向调整并稳定限位，画布可进入全屏后重新适配全图。
- 正文生成只产生候选正文，接受后才写入编辑器；AI 自检只产生结构化问题并由编辑器按钮手动触发，不在生成后自动产生费用。

## 4. 设置、详情与地图

- 设置页使用左侧分类列表和右侧唯一面板；模型供应商、任务路由、外观、导出与恢复各自独立。
- 每个模型供应商提供非生成的 `/models` 列表读取；目录可折叠、搜索并显示供应商与可用状态，任务路由和 Workflow 模型节点共用同一个可键盘选择的 Combobox，状态必须明确“未发起生成请求”。
- 连接测试与目录获取使用当前表单的地址、密钥、超时，新增供应商也可先测试再保存；空密钥沿用已存密钥。探测不自动保存连接，目录只在与已存连接一致时缓存；地址或密钥变化后旧目录失效，过期请求不得回填。保存失败保留输入；数字空值表示不修改。
- 已存连接但未选择任何任务模型时显示“已保存连接，待选择模型”，不能笼统显示“未配置”。
- Agent 预算写“每条消息最多内部步骤”，不得写成问题数或可继续对话的轮数；默认 20，帮助文案说明不限制后续提问。
- 模型密钥只显示掩码；生图任务保留独立供应商路由，Token Plan 文本密钥不能生图时明确提示需 `sk-` Provider，不显示可执行假状态。
- 生成详情展示 Workflow 版本、节点、工具、上下文、Token、错误和最终写入。
- 地图库与分块扩图共用不可变版本链路：确认后才成为当前版本，旧确认版标为“已被替代”；详情页在 1024 对齐画布上提供网格、四向扩图与单格重绘，遮罩外逐像素贴回、不羽化；未确认结果不替代正式地图。
- 没有真实 Provider 或后端数据时明确标为未启用，不填充假地图或假运行数据。

## 5. 全场景状态

| 场景 | 规格 |
|---|---|
| 首次加载 | 与最终布局同形的骨架，不整页转圈 |
| 空态 | 图标 + 一句话 + 一个可执行动作 |
| 生成中 | 流式正文、工具轨迹、节点状态和停止入口一致 |
| 模型未配置 | 明确指向设置页，输入或生成动作禁用 |
| 请求失败 | 原位说明原因并可重试 |
| 后端离线 | 明确离线，禁止继续提交写操作 |
| 高风险操作 | 展示真实差异，提供拒绝和批准，不静默执行 |
| 窄屏 | 保证当前主任务可用，其余栏可切换或折叠 |

## 6. 不可回退清单

`frontend/src/uiInvariants.test.ts` 负责机器保护；逻辑搬家可以改变断言位置，但不能减少决定覆盖。

| 类别 | 不可回退决定 |
|---|---|
| 启动页 | 主卡跟随真实最近作品；搜索几何居中；新建主动作不重复 |
| 工作台 | 左导航 / 中对话 / 右编辑审批的三栏语义不变 |
| 拖拽 | 两条边界位移 1:1；同一手势可关闭并反向恢复；重载恢复 |
| 标签栏 | 横向标签无可见滚动条；关闭按钮距离恒定；文件与章节标签尺寸一致 |
| 编辑区 | 原生纵向滚动条隐藏；Minimap 是唯一可见滚动轨道并与真实滚动同步 |
| 对话 | AI 回答无头像、无卡框；思考、工具轨迹与正文分区 |
| 数据真源 | 正文只有 files store 的 buffer；组件不维护第二份源码状态 |
| 写入刷新 | 写入后相关树和视图立即重读，不靠手动刷新且不破坏当前选择 |
| 搜索 | 匹配屏上格式化后的值；选中结果能定位到对应对象 |
| 人物 | 人物渲染面复用人物卡；头像走资产端点，文本走统一函数 |
| 设置 | 左列表 + 右面板；分组名只说一次；一个偏好只有一个写者；供应商（含默认）是一张统一列表，默认行无删除，保存结果常驻可读 |
| 字体 | UI、正文、代码各只有一个 token 出处；弹层不得退回浏览器默认字体 |
| 聚焦 | 禁止非零 outline、主色光晕和品牌色焦点边框 |
| 高风险 | 必须显示真实 diff；没有审批不能执行 |
| Workflow | 用途固定且每类只绑定一个当前流程；只显示六类已实现节点；画布保存、重载和发布版本语义一致；非法连接在落下时可见 |

效果类改动必须经平台 MCP 跑真实页面、输出几何数据并截图自审；测试全绿不能替代浏览器验收。
