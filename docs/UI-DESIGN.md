# UI 设计规格

最后整理：2026-09-09。本文件只保存当前视觉与交互决定；完成状态看 WORKSTREAM-PLAN.md，具体断言看 frontend/src/uiInvariants.test.ts。

## 0. 设计系统

### 0.1 色彩

实际令牌以 frontend/src/styles.css 顶部为准：

| 令牌 | Light | Dark | 用途 |
|---|---|---|---|
| bg | #f8f8f7 | #131314 | 应用与编辑底色 |
| surface | #ffffff | #1f2023 | 抬升面 |
| surface-alt | #f1f1ef | #191a1b | 次级面与输入 |
| border | #e4e4e1 | #313134 | 结构线 |
| text-1 | #1c1b1a | #ecebe9 | 主文本 |
| text-2 | #6d6b66 | #9d9b96 | 次文本 |
| accent | 朱砂 #c2492f | 朱砂 #e06a4e | 行动与选中 |
| success | #2f7d46 | #5cb176 | 成功 |
| warning | #8a6a12 | #c9a227 | 警告 |
| danger | #dc2626 | #f87171 | 破坏动作 |

蓝色强调由 data-accent=blue 切换；深浅主题由 data-theme 决定。正文文本对比度至少 4.5:1。压在高饱和色上的文字必须使用 on-accent/on-danger，不能散写白色。

### 0.2 字体与尺寸

- UI 使用 --ui；正文和成稿使用 --prose；代码使用 --mono。字体栈只在 styles.css 定义。
- 默认 UI 14px / 1.5，正文 17px / 1.9；动态数字使用 tabular-nums。
- 界面字号通过 --ui-zoom 缩放；所有指针坐标与拖拽位移必须经 toCssPx()。
- 间距阶梯为 4/8/12/16/24/32/48；圆角为 6/8/10px。
- 独立图标按钮 32×32，行内动作至少 24×24；移动端才要求 44×44。

### 0.3 动效与状态

- 常规过渡 150ms ease-out，只过渡 opacity、color、transform，禁止 transition: all。
- 按压 scale(0.96)；首屏不播放入场动画；流式文字直接追加。
- prefers-reduced-motion 下直接到终态；动效不得成为唯一反馈。
- 面板级空态用 lucide 图标 + 一句话 + 一个主动作；列表提示不加装饰图标。
- 保存/请求失败留在行内并给重试；成功路径或导出结果可用可关闭弹层。

## 0.7 控件纪律

1. 能用图标就不用常驻文字按钮；动作在对象 hover 或 focus-within 时出现。
2. 动作贴着对象，不造只装按钮的长条。
3. 一个对象只用一个名字，不用斜杠拼同义词。
4. 状态优先用圆点与颜色；解释性结构文字不上屏。
5. 展开/收起只用一个 chevron，无底框、无主色。
6. 同一信息只出现一次，跨栏重复视为缺陷。
7. 分隔优先留白，其次 1px 轻线。
8. 隐藏动作仍须键盘可达，并保留菜单或快捷键入口。
9. 空态、占位、注脚和回执不以句号收尾；正文与模型提示词除外。
10. 聚焦不画外圈或主色光晕，只允许光标和 border-strong。

## 0.8 动作图形语言

- 常规动作是 28×28 或 32×32 的无边框 lucide 图标按钮，必须同时有中文 aria-label 与 title。
- 打开/跳转用 ArrowRight，删除用 Trash2，应用用 Check，详情用 ScrollText，重试用 RotateCcw，复制用 Copy，思考用 Brain，工具轨迹用 Wrench。
- 同一排不放两个外形相同的图标；加载时图标位换 spinner；成功要有可见反馈。
- 方框主按钮只留给当前界面的唯一主行动。

## 0.9 不可回退清单

下表描述决定，frontend/src/uiInvariants.test.ts 负责机器实现。逻辑搬家可改断言定位，但不许减掉决定覆盖（D-33）。

| 类别 | 不可回退决定 |
|---|---|
| 标签栏 | 横向标签无可见滚动条；关闭按钮距离恒定；文件与章节标签尺寸一致 |
| 编辑区 | 正文、工具栏、源码面与缩略栏使用同一 bg；覆盖层 inset:0；缩略栏宽只由 --minimap-w 定义 |
| 对话 | AI 回答无头像、无卡框、无抬头；思考、工具轨迹、正文是三个独立语义区 |
| 思考 | 更小、更淡、斜体、正常段落；没有推理时不显示空入口 |
| 工具轨迹 | 使用 Wrench 与“工具轨迹 · N 步”，不能混入正文；每步展示名称、耗时与返回规模 |
| 控件 | 提案、命令与顶栏动作遵守 §0.8；说明文字不得替代 tooltip/aria-label |
| 提案卡 | 折叠控件在 `.proposal-head` 行内靠右、`white-space: nowrap`；展开时它的屏幕坐标不动（D-45），不许搬回 diff 列表末尾 |
| 空态 | 面板级空态有图标；文件栏除失败外不堆成功提示 |
| 状态 | 章节标签只有一个状态点；不显示“正文 + 简报”等结构解释 |
| 布局 | 三栏内容 min-width:0；工具栏不足时换行；栏可在同一拖拽手势中关闭并反向恢复 |
| 栏宽 | 几何常量由 paneLayout.ts 持有；正文栏恢复时保证可读宽度 |
| 文档视图 | 只有目录、人物档案和正文显示“渲染/源码”切换；两侧标签栏共用 ViewToggle |
| 数据真源 | 正文只有 files store 的 draft.md buffer；组件不维护第二份 sourceView 或 draft |
| 落地刷新 | 一次写入落地后左树立即重读 `chapters` + `briefs`，不靠手动刷新；重读不动选择，标签不得指向服务器上不存在的文件（D-46） |
| 写入落点 | 应用一张卡后，界面跟着**服务器回报的路径**走，不跟着卡片标题上那个路径走（D-47）：新建人物的标签页变成 `settings/characters/N.md`，空白模板 `new.md` 的条目与 pending 一并搬空，不留一个指向已消耗模板的格子 |
| 搜索 | 搜索匹配屏上格式化后的值；目录选中项应能定位到对应行 |
| 章节显示 | 标签只显示四位章号，完整章名进入 title 与无障碍名；树行显示章号 + 章名 |
| 章节动作 | 重命名只改 B 目录章名；插入后续 +1；删除后续 -1；确认弹层不要求打字 |
| 人物 | 人物文件渲染面复用 CharacterFormCard；头像走资产端点，文本走文件写口 |
| 设置 | 左列表 + 右面板；分组名只说一次；外观一个属性一个写者 |
| 字体 | 正文字体只有 --prose 一个出处；缩略栏从同一 token 读取 |
| 附件 | 输入框上方 chip，可删、失败保留；隐藏文件输入仍可访问 |
| 注入清单 | 同一文件聚合成一项，展开后名称、字数、状态只说一次；长摘录按真实溢出折叠 |
| 备份恢复 | 一行只给当前能执行的动作；恢复一章一次带回简报、正文与目录行 |
| 聚焦 | focus 规则禁止非零 outline、0 0 0 光晕和 accent 边框；CodeMirror 默认描边必须被中性规则覆盖 |

新增或推翻一条决定时，同一提交更新本节与 uiInvariants.test.ts，并做一次反向变异验证。

## 1. 书架

- 顶栏只保留产品入口与设置；书卡网格自适应。
- 整卡打开作品；右键提供编辑信息、更换封面、导出和删除。
- 删除确认不要求输入书名，默认焦点在取消；删除前由后端快照。
- 新建作品是页面唯一常驻主动作；封面使用 9 枚圆形预设和一个方形系统取色器。

## 2. 工作台

### 2.1 框架

顶部栏 48px；主体为可拖拽左/中/右三栏；底部只保留必要状态。栏的默认值、最小值与夹紧算法以 paneLayout.ts 为准，不在文档复制数字。

### 2.2 左栏

- ActivityRail 切换规划、设定库和对话。
- 规划树展示 A/B/C 与 chapters/NNNN/{brief.md,draft.md}；设定库列人物、世界观、伏笔和反馈入口。
- 搜索、折叠、新建与节点动作遵守 §0.7；右键菜单必须与当前后端能力一致。
- 目录默认是可搜索列表，可切源码；选中搜索结果应滚动到行。

### 2.3 中栏

- 支持自由对话、斜杠命令、@引用、附件和流式输出。
- 用户消息与 AI 正文保持安静；推理、工具轨迹、引用和 token 明细按需折叠。
- “生成章节”使用确认动作卡，作者确认后才进入现有生成流。
- 用户上滚时暂停自动吸底，并提供回到最新。

### 2.4 右栏

- 文件与章节可多标签打开；目录、人物与正文有专用渲染面，其他 Markdown 只显示源码。
- 正文是阅读主舞台，UI chrome 使用无衬线并退后。
- 保存、校验、审稿、摘要、终审与调用详情必须明确反馈成功或失败。
- 双栏对照、选区 Diff、内联审稿和版本历史属于延期项，不影响 v1 当前布局。

## 3. 设置与详情

- 设置页采用左侧分类列表 + 右侧唯一面板；模型供应商、任务路由、外观、导出与恢复各自独立。
- 模型密钥只显示掩码；未启用任务不显示可执行假按钮。
- GenerationRunDetailPage 展示单次调用、token 与注入清单。
- 绘画详情与地图面板在有真实后端前明确标为未启用；不填充假数据。

## 4. 全场景状态

| 场景 | 规格 |
|---|---|
| 首次加载 | 与最终布局同形的骨架，不整页转圈 |
| 空态 | 图标 + 一句话 + 一个可执行动作 |
| 生成中 | 流式正文、工具轨迹与停止入口状态一致 |
| LLM 未配置 | 明确指向设置页，输入或生成动作禁用 |
| 请求失败 | 原位说明原因并可重试 |
| 后端离线 | 明确离线，禁止继续提交会写入的动作 |
