# UI 设计清单 v4（当前权威版）

本文件是前端实现的唯一界面依据。每个页面按五段写清：**框架 / 功能点 / 按钮 / 风格 / 交互**。实现顺序：本清单 → Figma 全页面设计稿 → 前端代码 → 主人审批。

## 0. 设计系统（令牌）

### 0.1 色彩

强调色为朱砂红：印章/批注是中国长篇写作的文化母题，产品里所有"行动、选中、AI 产出"都指向它。中性色用冷暖居中的石墨灰，不用发黄的纸色。

| 令牌 | Light | Dark | 用途 |
|---|---|---|---|
| `bg` | `#F8F8F7` | `#131314` | 应用底色 |
| `surface` | `#FFFFFF` | `#1F2023` | 面板、卡片 |
| `surface-alt` | `#F1F1EF` | `#191A1B` | 悬浮、选中、输入框底 |
| `border` | `#E4E4E1` | `#313134` | 结构线（面板分隔、输入描边） |
| `text-1` | `#1C1B1A` | `#ECEBE9` | 主文本 |
| `text-2` | `#6D6B66` | `#9D9B96` | 次要文本、占位 |
| `accent` | `#C2492F` | `#E06A4E` | 主按钮、选中态、链接、AI 产出标记 |
| `accent-soft` | `#FBEDE9` | `#3B2B27` | 选中底色、徽章底 |
| `success` | `#2F7D46` | `#5CB176` | 定稿、已配置 |
| `warning` | `#8A6A12` | `#C9A227` | 编辑中、生成中 |
| `danger` | `#DC2626` | `#F87171` | 破坏操作、校验失败 |

规则：正文对比度 ≥ 4.5:1；状态色只用于徽章/点，不大面积铺色；**focus 不画圈**（§0.9，
第十五批 4.1/4.2 之后这条取代了早先的「focus ring 统一 accent 2px」）。

**`accent` 家族是别名，指向哪一套由 `data-accent` 决定（第十九批 19.3）**。两套原色各自
只在 `:root` 写一次，换色系换的是那三行别名，不是散在文件里的 74 处 `var(--accent)`：

| 色系 | Light（accent / strong / soft） | Dark | 实测：压界面底 / 压自身淡底 / 白字压 accent |
|---|---|---|---|
| 朱砂（默认） | `#C2492F` `#A83A24` `#FBEDE9` | `#E06A4E` `#E97F65` `#3B2B27` | 浅 4.90 / 4.29 / 4.90，深 4.92 / 4.06 / 2.78 |
| 蓝 | `#3568A0` `#28527F` `#EAF1F8` | `#5290D0` `#6BA7DD` `#1D2B3A` | 浅 5.77 / 5.07 / 5.77，深 4.86 / 4.29 / 2.82 |

蓝是照着「不比朱砂差」选的：浅色三项全过 AA，深色与朱砂同档。深色禁用态主按钮那一对
（`--control-disabled-accent-*`）在朱砂下是 4.00:1，蓝下换成了 5.07:1——**这一对要不要
把朱砂也抬上去，属品牌色决定，见 UI-BACKLOG 第二节**。

### 0.2 字体

| 用途 | 字体 | 规格 |
|---|---|---|
| UI 界面 | 思源黑体 Noto Sans SC（400/500） | 阶梯 12/13/14/15/16/20/24/32，行高 1.5 |
| 正文阅读与编辑 | 思源宋体 Noto Serif SC（400/600） | 17px，行高 1.9，段距 0.75em |
| 动态数字 | 界面字体 + `font-variant-numeric: tabular-nums` | 字数、token、时间防跳动 |

| 令牌 | 谁读它 |
|---|---|
| `--ui` | 根节点，一切界面文字 |
| `--prose` | 正文：章节编辑与调用记录里的成稿。缩略栏是 canvas，用 `tokenValue("--prose")` 回读，不在组件里再抄一份字体栈 |

规则：界面文字最小 12px；标题 `text-wrap: balance`，正文 `text-wrap: pretty`；根节点 `-webkit-font-smoothing: antialiased`。
正文字体可切到无衬线（`data-prose="sans"`，第十九批 19.3）；书架上的书名、封面字与头像底字是**装饰字**，
不跟着换——换的是「你要读的那篇正文」。

### 0.3 几何

- 圆角体系：控件 6px，卡片/弹层 10px；嵌套同心（外 = 内 + padding）。
- 间距阶梯：4/8/12/16/24/32/48。
- 阴影只做海拔：弹层 `0 8px 24px rgb(0 0 0 / 0.12)`（dark 0.4）；卡片默认靠 border 分层，悬浮加 `0 4px 12px rgb(0 0 0 / 0.08)`。
- 面板之间 1px border 分隔；不用 border 制造按钮立体感。

### 0.4 图标

统一 `lucide-react`，strokeWidth 1.5；一处一种描边；图标用 `currentColor`，状态靠 CSS 不换资源；图标按钮必须有 `aria-label` + Tooltip。
命中区：行内图标 24×24，独立图标 32×32，移动端 44×44。**旧的「≥40×40」作废**——它逼着每个图标都长成方块，正是主人否掉的「方框套方框」。

### 0.5 动效（make-interfaces-feel-better 全量采用）

| 场景 | 规格 |
|---|---|
| 通用状态过渡 | 150ms ease-out，只过渡 opacity/color/transform，禁 `transition: all` |
| 弹层进出场 | 进 200ms 上移 8px + 淡入；出 150ms 下移 4px + 淡出；可被打断 |
| 按压反馈 | `active: scale(0.96)`，禁更小值 |
| 首屏 | 不播放入场动画 |
| 批量入场 | 语义分组 stagger 100ms；高频交互（打字/悬停）零动画 |
| 流式输出 | 600ms 呼吸光标块；正文直接追加，不逐字动画 |
| 降级 | `prefers-reduced-motion` 全部直出终态 |

规则：动效永远不是唯一反馈，每个动画状态都有静态线索（颜色/图标/文字）。

### 0.6 组件基础

- **按钮**：默认形态是**无边框图标按钮**（见 §0.7）。方框按钮（primary accent 底白字 / secondary 描边 / danger）一个界面**最多一个**，且必须是该界面的主行动；其余一律降为图标或快捷键。高 32（紧凑）/ 36（标准），圆角 6，字重 500；加载中转 spinner 并禁点。
- **输入框**：高 36，surface-alt 底；**聚焦不画任何一圈**——只允许光标，加上自身边框提亮一档到 `--border-strong`（第六轮批注 16 起禁 accent ring，第十五批批注 4.2 把中性灰的圈也禁了，见 §0.9）；错误态 danger 描边 + 下方 12px 错误文案。
- **状态标记**：**优先用圆点与颜色，不用文字徽章**。空心灰环＝草稿、实心深灰点＝定稿、主色点＝待审、warning 点＋spinner＝生成中。文字徽章只在「一屏之内需要读出多个不同状态」时才用，且不得与标题重复。
- **弹层**：模态与确认气泡两种；Esc 关闭、焦点困住、关闭后焦点归还。
- **空态**：lucide 图标 + 一句话 + 一个主按钮，居中，无装饰插画。**面板级空态（撑满一栏的那种）必须有图标**，图标是装饰所以 `aria-hidden="true"`；列表/明细里的一行提示不算面板级空态，不加图标（否则就是装饰）。第十六批之前 `editor-empty`／`library-empty` 两处漏了，已补并由 `uiInvariants` 逐个钉住（第十七批批注 3）。
- **加载**：列表骨架屏（与最终布局同形），按钮内 spinner，流式用光标。
- **错误**：行内红字 + 建议 + 重试；toast 只用于后台结果（保存失败、导出完成）。

## 0.7 控件纪律：去方框 · 去常驻 · 去重复

主人 2026-09-04 第五轮 21 条批注，本质是**同一条原则的 21 次应用**，固化为通用纪律，
适用于此后所有面板与页面，不是只针对左栏：

| 条 | 规则 | 判据 |
|---|---|---|
| **一** | **能图标就不文字，能隐藏就不常驻。** 动作按钮静止 `opacity:0`、不占位、不推挤文字；鼠标进入**它所作用的那个容器**（页头／分组行／单条记录）才浮现 | 侧栏内不再有任何常驻按钮行；搜索、新建、折叠全部同理 |
| **二** | **动作贴着它的对象放，不做独立长条。** 「新建章节」在「章节」那一行，「新建对话」在对话页头，「调用记录」进功能图标排 | 出现「一整条 bar 只装按钮」即为违规 |
| **三** | **一个东西一个词，不用斜杠拼两个名字。** `卷 / 剧情弧` → `剧情弧`；`世界观 / 地图` → `世界观` | 树内标签不含 ` / ` |
| **四** | **状态用圆点与颜色，不用文字。** 「正文 + 简报」这类结构性说明**一律不上屏** | 行内不出现解释性后缀 |
| **五** | **展开／收起只放一个方向键。** 不加底框、不加主色 | chevron 无 background、无 border |
| **六** | **同一信息只出现一次。** 标题在 tab 上说过，工具栏就不再重复；状态在圆点上说过，就不再放文字徽章；连接状态在顶栏有过，底栏就不再放 | 跨栏重复即为 bug |
| **七** | **分隔要轻。** 半透明线、1px、hover 加粗不超过 1px；能靠留白分组就不画线 | 见 §0.5 与批注 9、10、21 |
| **八** | **隐藏 ≠ 消失。** 键盘 `focus-within` 同样浮现，右键菜单保留同名动作，能进快捷键的进快捷键（Ctrl+S） | 每条隐藏动作至少两条可达路径 |
| **九** | **提示语不是句子，不留句末标点。** 空态／占位／注脚／回执这类界面提示语行尾不加 `。`；句中分隔照旧；Agent 自己写的正文与发给模型的提示词不在此列 | 组件源码里不存在以 `。` 收尾的用户可见文案（`uiInvariants` 扫全部 `.tsx`，白名单逐条点名） |

**已按此原则作废或降级的既有控件**：侧栏页脚按钮行、常驻搜索框、文字状态徽章（草稿／定稿）、
文件编辑器「保存」按钮、编辑区顶栏的重复标题与「D 简报·视角·1477 字」说明、
底部状态栏的「后端 已连接」与重复章名、目录「列表／源码」双态控件（统一为顶栏一个渲染切换图标）。

## 0.8 动作按钮的图形语言（主人 2026-09-05 点名「要刻进守则」）

§0.7 条一早就写着「能图标就不文字」，而提案卡仍然摆着「在编辑器中打开 / 丢弃 / 应用」
三个文字按钮——**规则写了没执行，等于没有规则**。所以这一节把它变成可检查的条款：

| 条 | 规则 | 判据 |
|---|---|---|
| **一** | **动作 = 一个 28×28 无边框图标方块**。不写文字、不加边框、不给主/次两套尺寸 | `.proposal-btn`、`.command-actions button` 均 28×28 且 `border:0` |
| **二** | **词不消失，只搬家**：`aria-label` 给读屏，`title` 给悬停。图标不是把功能藏起来，是把功能从句子里解放出来 | 每个图标钮都有中文 `aria-label` + `title` |
| **三** | **语义用通用符号，不自创**：打开/跳转 `ArrowRight`｜丢弃/删除 `Trash2`｜确认/应用 `Check`（放主色方块）｜详情 `ScrollText`｜重试 `RotateCcw`｜复制 `Copy`｜思考过程 `Brain` | 新动作先查这张表，表里没有再挑 lucide 最通用的 |
| **四** | **同一排不出现两个同形图标**（跳转与打开必须分化） | 同排 `size` + 名称不重复 |
| **五** | **状态要有反馈**：写入中 = 图标位换 spinner；复制成功 = 旁边亮一下「已复制」。按下去毫无反应 = 假控件 | 与 §0.7 条八同判 |
| **六** | **解释性小字不上屏**：「小节标题与主键锁定 · AI 只改值」这类注脚属于文档，不属于卡片 | 卡片内不出现 `*-note` 说明行 |

**为什么值得单列一节**：主人原话——「这种控件的按钮要尽量设计得有设计感，高级一些，
比如说用图标的形式」。一排文字按钮是工程味；等宽图标 + 一个主色方块是产品味。

## 0.9 不可回退清单（机器看，不靠我记得）

2026-09-05 凌晨，主人在浏览器里一次指出四处「你改回去了」：标签条滚动条又占布局把 tab
压矮、关闭按钮到右边界的距离随文件名在 1 / 19 / 38px 之间跳、面包屑行比正文亮一档、

### 2.3 中栏：对话流（Codex 式）

**框架**：消息滚动区（flex-1）+ 底部输入坞。

**功能点**：
1. 消息四型：用户气泡（右，surface-alt）；AI 回复卡（surface，流式追加 + 尾部光标）；命令卡片（命令名 + 对象 + 状态徽章 + 进度/结果 + token 明细行 + 操作按钮）；错误卡（danger 左线 + 原因 + 重试）。
2. 斜杠命令面板（cmdk）：`/` 唤起，候选含命令名、参数占位、说明；上下键选择，`Tab` 补全。
3. `@` 引用选择器：节点搜索，选中生成可删引用 chip。
4. 消息级 token 明细：底部 `模型 · 耗时 · 展开用量`，展开显示输入/输出/总计（tabular-nums）。
5. 消息操作：hover `复制 / 引用到输入框 / 重试`。
6. 上下文指示：输入坞上方小字显示将带入的上下文（当前章节 + @引用）。

**按钮**：`发送`（primary，Enter 发送 / Shift+Enter 换行）；生成中变 danger `停止`。

**风格**：对话区 bg 底；命令卡左 2px accent 线；引用 chip accent-soft。

**交互**：流式自动吸底，用户上滚暂停并浮出"回到最新"；Agent 与写文 AI 用左边线颜色区分（Agent=accent，写文=success）。

### 2.4 右栏：编辑器（写作页）

**框架**：Tab 页签条 36px → 工具栏 40px → 正文区。页签可多开章节，未保存显实心 accent 点，中键关闭。

**功能点**：
1. 正文编辑（CodeMirror 6，原 TipTap 选型作废 X-04）：衬线 17px/1.9，页宽 720 居中；2s 防抖自动保存，显示 `已保存 HH:mm / 保存中...`。
2. Ctrl+F 查找条：命中高亮 + 计数 + 上下键跳转，Esc 关。
3. 双栏对照生成：左当前版右 AI 新稿（流式滚动），逐段 `采纳此段`，顶部 `全部采纳 / 放弃`；合并写入版本历史。
4. 选区修改：框选浮出工具条（`AI 修改 / 复制 / 批注`）→ Diff 视图（删除线暗红、新增 accent-soft）→ 逐处 `接受 / 拒绝`。
5. 内联审稿：问题片段 warning 高亮 + 批注气泡（维度+摘要+原文证据，可标已处理）；`审稿报告` 开右抽屉（420px）列七维：结论/证据/建议 + 总评分。
6. 版本历史：时钟图标开左抽屉，版本（时间+来源），预览 diff、确认后回滚。
7. 工具栏常驻：章节标题、状态徽章、字数、保存状态。

**按钮**：`审稿报告`、`版本历史`、`双栏对照开关`、`导出本章`；Diff `全部采纳 / 放弃`；抽屉 `重新审稿`。

**风格**：编辑区是唯一衬线主舞台，chrome 全部无衬线退后；正文区无边框卡片，只有页宽留白。

**交互**：Esc 退出 Diff/查找；批注 hover 显完整证据；历史 diff 用同一 jsdiff 渲染；保存失败状态变 danger + toast 重试。

### 2.5 底部状态栏

24px：左 = 后端连接点 + 当前书/章；右 = 今日 token 用量（点击进用量页）、字数、版本号；11px text-2。

### 2.6 全局快捷键

`Ctrl+K` 命令面板｜`Ctrl+P` 快速打开章节｜`Ctrl+F` 查找｜`Ctrl+S` 保存｜`Ctrl+B` 折叠左栏｜`Ctrl+J` 折叠中栏｜`Ctrl+Alt+N` 新建下一章简报｜`Esc` 关闭弹层。

> 新建快捷键选 `Ctrl+Alt+N` 而非 `Ctrl+N` / `Ctrl+Shift+N`：前者在浏览器里被「开新窗口」
