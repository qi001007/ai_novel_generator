## v3 修订（主人九条批注的绑定决策，前端先行）

### 3.0 编辑器范式：一切规划皆文档

> **后端契约（2026-09-03，D-01）**：文档视图不只是呈现方式，它就是四层规划的**唯一写入口**
> `PUT /api/novels/{id}/files/{path}`。本节所有界面都往这一条入口写，禁止再开第二条。

A/B/C/D 四层规划**各就是一份 Markdown 文档**，内容一律在右栏代码编辑器里改，形式向"改正文"看齐，不用表单堆叠，也不再有第二套编辑视图（`PlanningPanel` 表单视图已于 2026-09-02 删除，帧 06/07 同步下架）：

| 层 | 文件 | 结构 = 锁 | 值 = 可改 |
|---|---|---|---|
| A | `blueprint.md` | 五个小节标题 `## 主线/终局/核心冲突/主题/约束` | 各节正文 |
| B | `toc.md` | 每条 `## 第 N 章` 的章号前缀 | 同行章名、`- **剧情功能**：` / `- **备注**：` |
| C | `arcs.md` | 每条 `## 弧 N` 的弧号前缀 | 同行弧名与六个 bullet |
| D | `chapters/00NN/brief.md` | 文件名章号 + `- **章节号** / - **所属弧**` | 其余 bullet 与五个 `##` 小节正文 |

- 每个文件顶部一条 `>` 引用块写明本层的锁规则；锁住的行在左侧 2px rail 上标出，标题与主键改不动，改了直接 422。
- 数据库仍是唯一真源：文件是投影，`read_file()` 现渲染、`write_file()` 解析回列，换格式零数据迁移。
- 选 Markdown 而非 YAML 的理由（主人 2026-09-02 拍板）：将来要把规划注入模型上下文与分块向量化（注：向量化**不是 v1 承诺**，触发条件见 D-12），MD 是模型读写最稳的格式，人也读得更省事。
- 对话页可用 `/plan A|B|C|D <指令>` 让 AI 起草任意层内容，AI 只能以 ` ```md @路径 ` 围栏给出**提案**，点「应用」才写入。

### 3.1 对话流 Codex 化

1. **模式切换**：输入坞左下角分段控件 `计划 / 写作`（计划模式=规划讨论与蓝图起草，写作模式=正文生成与修改；AI 行为与上下文按模式区分）。

### 3.4 人物卡片修复

设计模式声明（impeccable）：本产品全部界面属于 **Operate 模式**（完成任务型工具）——可扫读、一致性、键盘效率优先于装饰表达；品牌感只活在精确的细节里。设计刻度：变化 5/10、动效 3/10、密度 7/10（工作台 7，书架 4）。

## 0. 设计系统（令牌）

### 0.1 色彩

强调色为朱砂红：印章/批注是中国长篇写作的文化母题，产品里所有"行动、选中、AI 产出"都指向它。中性色用冷暖居中的石墨灰，不用发黄的纸色。

| 令牌 | Light | Dark | 用途 |
|---|---|---|---|
| `bg` | `#F8F8F7` | `#131314` | 应用底色 |
| `surface` | `#FFFFFF` | `#1C1C1E` | 面板、卡片 |
| `surface-alt` | `#F1F1EF` | `#26262A` | 悬浮、选中、输入框底 |
| `border` | `#E4E4E1` | `#313134` | 结构线（面板分隔、输入描边） |
| `text-1` | `#1C1B1A` | `#ECEBE9` | 主文本 |
| `text-2` | `#73716C` | `#9D9B96` | 次要文本、占位 |
| `accent` | `#C2492F` | `#E06A4E` | 主按钮、选中态、链接、AI 产出标记 |
| `accent-soft` | `#FBEDE9` | `#3B2B27` | 选中底色、徽章底 |
| `success` | `#2F7D46` | `#5CB176` | 定稿、已配置 |
| `warning` | `#A8811F` | `#C9A227` | 编辑中、生成中 |
| `danger` | `#DC2626` | `#F87171` | 破坏操作、校验失败 |

规则：正文对比度 ≥ 4.5:1；状态色只用于徽章/点，不大面积铺色；focus ring 统一 accent 2px。

### 0.2 字体

| 用途 | 字体 | 规格 |
|---|---|---|
| UI 界面 | 思源黑体 Noto Sans SC（400/500） | 阶梯 12/13/14/15/16/20/24/32，行高 1.5 |
| 正文阅读与编辑 | 思源宋体 Noto Serif SC（400/600） | 17px，行高 1.9，段距 0.75em |
| 动态数字 | 界面字体 + `font-variant-numeric: tabular-nums` | 字数、token、时间防跳动 |

规则：界面文字最小 12px；标题 `text-wrap: balance`，正文 `text-wrap: pretty`；根节点 `-webkit-font-smoothing: antialiased`。

### 0.3 几何

- 圆角体系：控件 6px，卡片/弹层 10px；嵌套同心（外 = 内 + padding）。
- 间距阶梯：4/8/12/16/24/32/48。
- 阴影只做海拔：弹层 `0 8px 24px rgb(0 0 0 / 0.12)`（dark 0.4）；卡片默认靠 border 分层，悬浮加 `0 4px 12px rgb(0 0 0 / 0.08)`。
- 面板之间 1px border 分隔；不用 border 制造按钮立体感。

### 0.4 图标

统一 `lucide-react`，strokeWidth 1.5；一处一种描边；图标用 `currentColor`，状态靠 CSS 不换资源；图标按钮必须有 `aria-label` + Tooltip。
命中区：行内图标 24×24，独立图标 32×32，移动端 44×44。**旧的「≥40×40」作废**——它逼着每个图标都长成方块，正是主人否掉的「方框套方框」。

### 0.5 动效（make-interfaces-feel-better 全量采用）

| 场景 | 规格 |
|---|---|
| 通用状态过渡 | 150ms ease-out，只过渡 opacity/color/transform，禁 `transition: all` |
| 弹层进出场 | 进 200ms 上移 8px + 淡入；出 150ms 下移 4px + 淡出；可被打断 |
| 按压反馈 | `active: scale(0.96)`，禁更小值 |
| 首屏 | 不播放入场动画 |
| 批量入场 | 语义分组 stagger 100ms；高频交互（打字/悬停）零动画 |
| 流式输出 | 600ms 呼吸光标块；正文直接追加，不逐字动画 |
| 降级 | `prefers-reduced-motion` 全部直出终态 |

规则：动效永远不是唯一反馈，每个动画状态都有静态线索（颜色/图标/文字）。

### 0.6 组件基础

- **按钮**：默认形态是**无边框图标按钮**（见 §0.7）。方框按钮（primary accent 底白字 / secondary 描边 / danger）一个界面**最多一个**，且必须是该界面的主行动；其余一律降为图标或快捷键。高 32（紧凑）/ 36（标准），圆角 6，字重 500；加载中转 spinner 并禁点。
- **输入框**：高 36，surface-alt 底，focus 2px accent ring；错误 danger ring + 下方 12px 错误文案。
- **状态标记**：**优先用圆点与颜色，不用文字徽章**。空心灰环＝草稿、实心深灰点＝定稿、主色点＝待审、warning 点＋spinner＝生成中。文字徽章只在「一屏之内需要读出多个不同状态」时才用，且不得与标题重复。
- **弹层**：模态与确认气泡两种；Esc 关闭、焦点困住、关闭后焦点归还。
- **空态**：lucide 图标 + 一句话 + 一个主按钮，居中，无装饰插画。
- **加载**：列表骨架屏（与最终布局同形），按钮内 spinner，流式用光标。
- **错误**：行内红字 + 建议 + 重试；toast 只用于后台结果（保存失败、导出完成）。

## 0.7 控件纪律：去方框 · 去常驻 · 去重复

主人 2026-09-04 第五轮 21 条批注，本质是**同一条原则的 21 次应用**，固化为通用纪律，
适用于此后所有面板与页面，不是只针对左栏：

| 条 | 规则 | 判据 |
|---|---|---|
| **一** | **能图标就不文字，能隐藏就不常驻。** 动作按钮静止 `opacity:0`、不占位、不推挤文字；鼠标进入**它所作用的那个容器**（页头／分组行／单条记录）才浮现 | 侧栏内不再有任何常驻按钮行；搜索、新建、折叠全部同理 |
| **二** | **动作贴着它的对象放，不做独立长条。** 「新建章节」在「章节」那一行，「新建对话」在对话页头，「调用记录」进功能图标排 | 出现「一整条 bar 只装按钮」即为违规 |
| **三** | **一个东西一个词，不用斜杠拼两个名字。** `卷 / 剧情弧` → `剧情弧`；`世界观 / 地图` → `世界观` | 树内标签不含 ` / ` |
| **四** | **状态用圆点与颜色，不用文字。** 「正文 + 简报」这类结构性说明**一律不上屏** | 行内不出现解释性后缀 |
| **五** | **展开／收起只放一个方向键。** 不加底框、不加主色 | chevron 无 background、无 border |
| **六** | **同一信息只出现一次。** 标题在 tab 上说过，工具栏就不再重复；状态在圆点上说过，就不再放文字徽章；连接状态在顶栏有过，底栏就不再放 | 跨栏重复即为 bug |
| **七** | **分隔要轻。** 半透明线、1px、hover 加粗不超过 1px；能靠留白分组就不画线 | 见 §0.5 与批注 9、10、21 |
| **八** | **隐藏 ≠ 消失。** 键盘 `focus-within` 同样浮现，右键菜单保留同名动作，能进快捷键的进快捷键（Ctrl+S） | 每条隐藏动作至少两条可达路径 |

底部状态栏的「后端 已连接」与重复章名、目录「列表／源码」双态控件（统一为顶栏一个渲染切换图标）。

## 0.8 动作按钮的图形语言（主人 2026-09-05 点名「要刻进守则」）

§0.7 条一早就写着「能图标就不文字」，而提案卡仍然摆着「在编辑器中打开 / 丢弃 / 应用」
三个文字按钮——**规则写了没执行，等于没有规则**。所以这一节把它变成可检查的条款：

| 条 | 规则 | 判据 |
|---|---|---|
| **一** | **动作 = 一个 28×28 无边框图标方块**。不写文字、不加边框、不给主/次两套尺寸 | `.proposal-btn`、`.command-actions button` 均 28×28 且 `border:0` |
| **二** | **词不消失，只搬家**：`aria-label` 给读屏，`title` 给悬停。图标不是把功能藏起来，是把功能从句子里解放出来 | 每个图标钮都有中文 `aria-label` + `title` |
| **三** | **语义用通用符号，不自创**：打开/跳转 `ArrowRight`｜丢弃/删除 `Trash2`｜确认/应用 `Check`（放主色方块）｜详情 `ScrollText`｜重试 `RotateCcw`｜复制 `Copy`｜思考过程 `Brain` | 新动作先查这张表，表里没有再挑 lucide 最通用的 |
| **四** | **同一排不出现两个同形图标**（跳转与打开必须分化） | 同排 `size` + 名称不重复 |
| **五** | **状态要有反馈**：写入中 = 图标位换 spinner；复制成功 = 旁边亮一下「已复制」。按下去毫无反应 = 假控件 | 与 §0.7 条八同判 |
| **六** | **解释性小字不上屏**：「小节标题与主键锁定 · AI 只改值」这类注脚属于文档，不属于卡片 | 卡片内不出现 `*-note` 说明行 |

**为什么值得单列一节**：主人原话——「这种控件的按钮要尽量设计得有设计感，高级一些，
比如说用图标的形式」。一排文字按钮是工程味；等宽图标 + 一个主色方块是产品味。
