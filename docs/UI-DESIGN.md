## 0. 全局基调

- 深浅双主题，默认跟随系统，工作台顶栏可手动切换
- 正文区衬线字体（如思源宋体 / Noto Serif SC），工作区无衬线
- 卡片圆角 8px 以内，克制阴影；每套主题只用一个强调色
- 所有状态标签用中文：草稿、生成中、已生成、AI 已审、待终审、定稿
- 组件基座：命令面板用 cmdk、树用 react-arborist、编辑器用 TipTap、Diff 用 jsdiff 自渲染（见 REQUIREMENTS.md 第 9 节）

## 1. 书架首页 `/`

- 顶栏：产品名 + 主题切换按钮

书卡：
- 封面：纯色 + 书名首字占位（AI 生成封面放 P2）

新建作品：
- 右上“新建作品”按钮 → 弹窗向导：书名 → 简介 → 目标篇幅 → 文风约束 → 创建

## 2. 工作台 `/novels/:id`

三栏布局：
- 左栏（可折叠）：双根树
- 中栏：对话流
- 右栏：编辑器

顶栏：返回书架、书名、LLM 状态点（绿=已配置）、Token 用量入口、主题切换

左栏双根树：
- 根 1 “规划”：A 全本蓝图 → B 目录 → C 卷/弧 → D 章节（react-arborist 实现）
- 根 2 “设定库”：人物 / 世界观 / 伏笔 / 地点 / 阵营分组（P2 阶段除人物外陆续开放）
- 节点：折叠箭头 + 名称 + 状态徽章；当前编辑节点高亮
- 点击节点 → 右栏显示对应内容（章节 → 编辑器，其余 → 对应编辑表单）

验收勾选：
- [x] v1 三栏布局与折叠（Figma：Tree/Chat/Editor 三栏骨架已建）
- [x] v1 双根树渲染与状态徽章（规划根 + 5 行完成；设定库根待额度恢复）
- [ ] v1 节点点击联动右栏

## 3. 对话流（中栏）

消息类型：
- 用户消息：右对齐浅底
- AI 回复：流式逐字更新，左对齐卡片
- 命令卡片：/generate、/review、/summary 等的结构化卡片（进度 → 结果摘要 → 操作按钮）
- 错误卡片：失败原因 + 重试按钮

输入框（底部固定）：
- 输入 / 唤起命令面板（cmdk 实现：候选列表 + 过滤 + 键盘上下选择）
- 输入 @ 唤起引用选择器（树节点搜索）
- Enter 发送、Shift+Enter 换行

消息明细（参照 OpenCode）：
- 每条 AI 消息底部一行小字：模型、耗时、“展开用量”
- 展开后显示：输入 token / 输出 token / 总计 / 来源功能

- [ ] v1 四类消息渲染（Figma 待额度恢复后补）
- [ ] v1 斜杠命令面板
- [ ] v1 @引用选择器
- [ ] v1 流式更新
- [ ] v1 消息级用量展开

## 4. 编辑器（右栏 / 写作页）

正文编辑：
- 衬线字体、合理行距、最大页宽居中
- 字数统计、保存状态（已保存 / 保存中…）
- Ctrl+F 顶部浮出查找条（高亮 + 上下跳转）

双栏对照生成：
- /generate 后左“当前版本”右“AI 新稿”，双栏流式滚动
- 每段带“采纳此段”按钮；顶部“全部采纳 / 放弃”
- 合并完成后回到单栏编辑

选区修改：
- 框选文字 → 浮动工具条“AI 修改”
- 输入指令 → Diff 视图：原文删除线、新文高亮
- 逐处接受/拒绝，全部处理完回到编辑态

内联审稿：
- AI 七维审稿结果：问题片段高亮 + 批注气泡（维度名 + 摘要 + 原文证据）
- 右侧可展开抽屉：完整七维报告（每维：结论、证据、建议）
- 批注可标记“已处理”

版本历史：
- 编辑器顶栏历史图标 → 侧栏列出历史版本（时间 + 来源：AI 生成 / 人工编辑）
- 可预览、可回滚（回滚前需确认）

自动保存：
- 停止输入约 2 秒后自动保存，顶部显示保存状态

- [ ] v1 选区 Diff 修改

## 5. 人物卡片（设定库 → 人物）

- 顶部：分类标签页（全部 / 主角团 / 重要配角 / 小 Boss / 龙套）+ 搜索框
- 卡片墙：头像（占位色块，P2 支持 AI 头像）、姓名、级别徽章、活跃章节范围（如 45-78）
- 点击卡片 → 弹出详情层：
  - 基本信息：姓名、身份、级别、活跃章节（预计窗口 vs 实际出现）
  - 目标与动机、人物弧线
  - 关系列表（对象 + 关系描述）
  - 出场章节列表
- 详情层内直接编辑，保存后回到卡片墙

- [ ] v1 卡片墙
